# Archived: first Optuna study (18 base features, distance-only labels)

Kept as the record of the first Bayesian search (50 trials, CV top-1 0.8492 -> 0.8515).
It was run before the heading-aware labels and the context features were added, so its
numbers are not comparable with the current study in `results/hpo/xgb_study.db`
(24 features). Not used by any code.
